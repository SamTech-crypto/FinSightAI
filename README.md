## 🛠️ Features

### 📈 Dashboard
- Visualizes budget forecasts
- Highlights unusual financial entries using IQR anomaly detection

### 🤖 Chatbot
- Ask finance-related questions in natural language
- Powered by GPT-4 (via OpenAI)

### 📝 Risk Analyzer API
- Upload financial documents (PDF, Excel, CSV)
- Extracts text and evaluates risks using AI
- Available at `/analyze` via FastAPI
